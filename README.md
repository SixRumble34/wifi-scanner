# Windows Wi-Fi Scanner

A Python-based Windows command-line utility for scanning available Wi-Fi networks and displaying information about the current wireless connection.

## Features

- Scan available Wi-Fi networks
- Display SSIDs
- Display signal strength
- Display wireless security
- Identify password-protected networks
- Display the current Wi-Fi connection
- Display connection state
- Windows-only implementation

## Requirements

- Windows 10 or Windows 11
- Python 3.x
- A wireless network adapter

## Usage

Open PowerShell or Command Prompt in the project directory and run:

```text
python windows_wifi_scanner.py
